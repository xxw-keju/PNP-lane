# 公开内容与本地数据

仓库只包含程序源码、网页静态资源、文档、示例配置和合成测试数据。示例账号、邮箱与路径是占位符，不包含原部署的账号配置、本机绝对路径、会话 id 或运行记录。

不会随仓库或发行包分发的内容：

- GitHub token、登录配置、SSH 密钥、环境变量文件。
- Codex/Claude 对话、JSONL、会话数据库及私有工具输入。
- 任务缓存、评分记录、作业清单、证明草稿和服务日志。
- 原部署的 Git 历史、提交者私人邮箱和本机配置。

GitHub 仓库地址、上游项目地址以及系统标准目录名称是公开或通用配置。`config.example.json` 不含有效凭据。测试里的密码和 token 字符串仅用于验证凭据助手与脱敏逻辑，是人工构造的假数据。

运行时的身份、仓库与会话路径由使用者配置；运行数据保存在配置的数据目录。日志和作业记录可能包含使用者自己的本机路径，因此不应把运行目录直接上传。`.gitignore` 排除了常见配置、日志、数据库、会话及状态目录。

程序访问配置的公开任务源与 GitHub。网页仅绑定本机 loopback，API 为只读。会话观察需主动配置本地路径；发布证明需显式运行 `prepare` / `run`。`init --from-gh` 使用 GitHub noreply 邮箱，认证仍由本机 GitHub CLI 管理。
